# Where are the raylib files?
To reduce bloat, I do not include the raylib source and header files in the repo. To add the source files, follow the steps below.
- Download the Raylib 6.0 tarball/zip from https://github.com/raysan5/raylib/releases
- Extract the contents
- Copy the `include` and `lib` folders into the `Raylib Source` directory in this repo
- Get coding!
